01 / ACERVO VISUAL

Galeria

Cada cena usa uma imagem: a prévia mostra o arquivo inteiro, e o Cloudinary gera versões leves para exibição. Selecione JPG, PNG, WebP ou AVIF de até 8 MB e salve para publicar. Também é possível usar um caminho assets/… ou URL HTTPS.

Os envios são autorizados pelo serviço de imagens e salvos no Cloudinary. O painel gera automaticamente uma versão otimizada para a galeria, sem duplicar o arquivo como miniatura.
