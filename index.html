07 / ANTES DE PARTIR

Quer saber
mais?

Esta é a página oficial de GTA VI?+

Não. Sunset Stories é uma experiência independente de fã e não tem vínculo com a Rockstar Games.

As imagens representam o jogo final?+

A galeria reúne imagens fornecidas como referências visuais. Este projeto não confirma a origem oficial de cada arte nem representa recursos ou cenas do jogo final.

Posso jogar ou baixar GTA VI aqui?+

Não. Esta página é uma experiência visual. Informações de compra e disponibilidade devem ser consultadas nos canais oficiais.

Como usar a galeria?+

Filtre por atmosfera, abra uma cena e use os controles para navegar ou baixar a imagem. Isso não baixa arquivos do jogo.

Posso desligar as animações?+

Sim. Use o botão Movimento no topo. A página também respeita a preferência de movimento reduzido do seu dispositivo.
